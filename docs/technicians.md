# Техниктер және пломба орнату

Бұл бөлім резиденттерге емес, газ қызметінің далалық техниктеріне арналған. Техник тұрғын емес, қызметкер: оған Telegram арқылы қолжетімділікті тек SUPER_ADMIN береді.

1. «Пломбалар» бөлімінде (тек SUPER_ADMIN) SUPER_ADMIN техниктің Telegram ID-сын (боттың `/start` хабарламасынан алынады) және аты-жөнін енгізіп, техникті тіркейді. Телефон немесе өзге растау талап етілмейді — бұл қызметкерге арналған қолжетімділік, абонент тізілімінен бөлек.
2. Техниктің Telegram ID-сы тіркелген кезде бот оған резидент мәзірінің орнына техник мәзірін («🔧 Пломба орнату» батырмасы) көрсетеді. Тіркелмеген немесе бұғатталған Telegram ID үшін бот әдеттегі резидент ағынын көрсетеді.
3. Пломба орнату ағыны: дербес шот нөмірі → есептегіш нөмірі → екеуін растау (дұрыс емес болса, толық қайта енгізу) → есептегіштің ағымдағы көрсеткіші → орнатылатын пломба нөмірі → фото → геолокация (міндетті) → соңғы растау. Барлық өрістерді техник қолмен енгізеді; дербес шот абоненттер тізілімімен автоматты түрде байланыстырылмайды (деректер тәуелсіз сақталады).
4. Фото `application_files`-де `SEAL_PHOTO` түрімен сақталады және бір рет қана пайдаланылады: бір фото екінші пломба жазбасында қайта қолданылса, сервер қабылдамайды.
5. Жазба `seal_installations` кестесінде сақталады: техник, дербес шот, есептегіш нөмірі, көрсеткіш, пломба нөмірі, фото, latitude/longitude және уақыты. Idempotency кілті қайталап басу салдарынан екі жазба жасалуын болдырмайды.
6. Админ-панельде («Пломбалар» → «Пломба орнату есептері») барлық жазба кестеде көрінеді; координаттар бағанындағы сілтеме Google Maps-те нақты орынды ашады. CSV/Excel экспортта да координаттар Google Maps сілтемесі ретінде (Excel-де — басуға болатын ұяшық) беріледі.
7. Техниктерді басқару («Пломбалар» → «Техниктер»): тізім, жаңасын қосу, атын өзгерту немесе бұғаттау (optimistic locking — `version`).

Миграция `b8c9d0e1f2a3` `technicians` және `seal_installations` кестелерін қосады, `application_files.file_type` тексеру шартына `SEAL_PHOTO`-ны қосады (баған ені өзгермейді — 10 таңба бар кеңістікке сияды).

Қауіпсіздік: ішкі bot API `X-Bot-Key` арқылы қорғалған; іздеу және жіберу лимиттелген (rate limit); фото меншігі мен түрі серверде тексеріледі; әкімшілік әрекеттер (техник қосу/өзгерту, экспорт) SUPER_ADMIN рөлімен және `audit_logs`-пен шектеледі.

Тестер: `tests/test_technicians.py` (backend CRUD, bot-auth аралық нүктелер, фото қайталау/иесіздік тексерулері, экспорт) және `tests/test_bot.py` ішіндегі техник мәзірі мен толық пломба орнату ағыны тестері.
